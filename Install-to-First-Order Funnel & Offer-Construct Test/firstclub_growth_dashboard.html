Business interpretation

What the analysis says — and what it cannot say
Decision support

What we learned

  • About 12.16% of sessions containing a cart event also contain a purchase event in the same session.
  • That leaves an 87.84% same-session non-conversion rate to investigate.
  • Offer cost changes how much conversion lift is required to offset the modeled incentive.

What we should do next

  • Investigate checkout, payment, delivery-fee and basket-minimum friction in first-party data.
  • Run a randomized user-level experiment and evaluate contribution per eligible user, not conversion alone.
  • Replace public benchmark assumptions with FirstClub's verified AOV, margin and delivery subsidy.

Model assumptions

  • Average order value: ₹1,200 (business-context assumption, not measured from the funnel data).
  • Contribution margin before promotion: 25% (illustrative assumption).
  • Free-delivery subsidy: ₹60 per redeemed order (illustrative assumption).
  • 10% discount cost: ₹120 on the assumed ₹1,200 basket.

Definitions & limitations

  • Cart-session conversion = cart sessions also containing a purchase ÷ all cart sessions.
  • Same-session non-conversion is not the same as permanent abandonment; a later session can still convert.
  • The dataset has no install events, first-ever-order flag or experimental offer assignments.
  • Use FirstClub's true eligible-customer baseline to recalculate sample size before launching any live test.
